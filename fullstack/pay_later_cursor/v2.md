# 🎯 **Merchant Wallet System Implementation - v2**

## 📋 **Project Overview**

### **Business Logic Change:**
- **Current**: User makes purchases → Merchant gets paid → User owes PayLater
- **New**: User adds money to merchant wallet → Merchant gets full amount → User owes PayLater (amount + fee)

### **User Flow Example:**
```
User (Credit Limit: ₹1000)
├── Selects KFC (10% fee)
├── Adds ₹500 to KFC wallet
├── KFC receives: ₹500 (full amount)
├── User owes PayLater: ₹550 (₹500 + 10% fee)
└── User credit limit: ₹500 remaining
```

- **New Permissions**: `wallet:read/write`, `credit:read/write`, `wallet_transactions:read/write`
- **Risk Level**: 🟢 **LOW** - Just adding new permissions

### **Database Indexes:**
